`GeoIP2-Country-Test.mmdb` is MaxMind's test database from
https://github.com/maxmind/MaxMind-DB (`test-data/`), MIT licence (`LICENSE-MIT`;
Apache 2.0 is the alternative; Copyright (c) 2013 - 2026 by MaxMind, Inc.). It holds a few test networks only, for example
`89.160.20.112` (SE), `81.2.69.160` (GB) and `2001:218::1` (JP). It is not the
GeoLite2 database, which is never committed (see README.md, deployment step 6).
